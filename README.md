## 🧭 Rotina

1. Estudar (bootcamp + teoria da semana).
2. Escrever/atualizar a nota da fase e 2–3 termos no glossário.
3. Commit no fim de cada sessão: `git commit -m "S03: métricas de classificação"`.
4. Sexta: atualizar o checklist de níveis no Notion e escrever a retrospectiva.

> ⚠️ Toda prática ofensiva (pentest, exploração) é feita apenas em laboratório próprio ou em ambientes autorizados.
