# 💬 Biblioteca de prompts de segurança

Formato de cada prompt (`nome-do-prompt.md`):

- **Tarefa:** o que ele resolve (ex.: resumir alerta do GuardDuty).
- **Prompt:** o texto usado.
- **Entrada de teste:** exemplo fictício/sanitizado.
- **Resultado:** o que funcionou, o que falhou, alucinações observadas.
- **Versão:** v1, v2… com o que mudou.
